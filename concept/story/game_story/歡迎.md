# 遊戲設定庫

> [!important] 先讀
> 所有設定的正史層級、統一術語與衝突裁決，集中於 [[00_正史與文件權威]]。

這裡是遊戲世界觀、角色、勢力與故事的創作空間。

> [!important] 與正式遊戲內容的界線
> 這個 vault 可以自由記錄靈感與提案，但只有標記為「已定案」的設定才屬於目前 canon；「已實作」還必須能在專案的場景、腳本、資料或測試中獲得驗證。已實作玩法的權威文件是專案根目錄的 `docs/12_GAME_DESIGN.md`。

## 從這裡開始

1. 先讀 [[00_正史與文件權威]]，確認什麼是正史、提案與 runtime 現況。
2. 到 [[00_遊戲設定總覽]] 閱讀目前遊戲核心。
3. 到 [[01_世界觀/世界觀核心]] 查看世界最重要的三條規則。
4. 還不確定放哪裡的想法，先丟進 [[90_收件匣/靈感收件匣]]。
5. 想法成形後，使用 `99_模板` 裡的模板建立正式條目。

## 狀態約定

| 狀態 | 用法 |
|---|---|
| 靈感 | 尚未整理，可以互相矛盾 |
| 草稿 | 已形成方向，仍可大幅修改 |
| 討論中 | 有數個方案或關鍵問題未決 |
| 已定案 | 目前採用的 canon 設定 |
| 已實作 | 已定案，且已在遊戲 runtime 中驗證 |

設定改變時，優先修改真正擁有該設定的筆記，其他地方以 Wiki 內部連結引用，避免複製出數個不同版本。
