# 終結技組合與命名

## 設計目標

終結技採現代奇幻句型，從古籍抽取一至兩個雅詞，再與 Combo 的動作、元素或結果重新組合。古籍只提供意象，不直接搬用完整成語；名稱要文雅、有畫面，也要保留高階戰技的力度。

本文件的古籍命名規則只套用在「終結技」，不回頭修改 Combo 名稱。Combo 必須維持直觀功能名，讓玩家從名稱就能預判加傷、攻速、範圍、防禦、元素或治療用途；酷感只能作為第二順位。

- 每一張現有 Combo／Healing 招式都必須有一個「同卡 ×3」終結技。
- 所有終結技名稱限制為 4～6 個漢字，不使用標點拆成主副標題。
- 同卡終結技負責把該招式的核心用途推到極致。
- 跨卡終結技讀取順序；同三張卡但順序不同，可以是不同配方。
- 防禦終結技可以建立結界、反擊或拒絕控制，不必造成高傷害。
- 治療終結技可以復甦、護盾或共享生命，不必以攻擊作收尾。
- 本文件是 OB 擴充規劃；目前 runtime 仍只有 `data/combo_finishers.json` 的 5 個配方。

## 命名結構

| 層級 | 格式 | 用途 |
|---|---|---|
| 動作語 | 2–4 字 | 描述斬、踏、回、落、聚、散等主要動作 |
| 景象語 | 2–4 字 | 描述風、雨、月、霜、雷、花與回聲等戰鬥畫面 |
| 完整名稱 | 4–6 字為主 | UI 與語音都使用同一短名，不再拆成主副標題 |

### 用詞方向

| 類型 | 優先詞彙 | 避免詞彙 |
|---|---|---|
| 物理攻擊 | 希聲、流光、繁音、月輪、相應 | 千軍、八荒、殲滅、終焉 |
| 防禦反擊 | 守一、含章、無移、返照、歸身 | 鎮嶽、孤城、絕對領域 |
| 元素 | 流火、凝華、春醒、蘭芷、成蝕 | 煉獄、殺界、天罰、爆殺 |
| 治療 | 載陽、來復、共脈、長春、不窮 | 返魂、永生神術、聖域等直白大詞 |

常用古籍詞根包括《道德經》的「希聲、若存、守一」、《周易》的「相應、含章、來復、既濟、不窮」、《莊子》的「扶搖」，以及《詩經》的「載陽」。這些詞只作命名材料，最後名稱仍須對應 Combo 特性。

## 跨卡終結技

跨卡配方仍固定為三張，並依輸入順序判定。

| 順序 | 終結技名稱 | 核心效果 |
|---|---|---|
| 強攻律動 → 加速節拍 → 回聲齊射 | **希聲繁羽** | 把加速期間的攻擊節奏灌入齊射，每一發回聲依節拍產生追擊。 |
| 橫掃延伸 → 巨型弧斬 → 回聲齊射 | **天光回羽** | 先用大弧聚敵，再生成八方向回聲刃陣，外圈折返斬向中心。 |
| 鋼鐵意志 → 石之形 → 反擊守勢 | **守一返照** | 建立不動石城，吸收領域內攻擊並以相同方向、屬性返還。 |
| 疾風步 → 奧術吐息 → 深層蓄能 | **扶搖泉湧** | 移動時沿路生成 AP 星脈，拾取後突破 AP 上限並延長下一個 Combo。 |
| 烈焰灌注 → 霜爆灌注 → 風暴充能 | **水火既濟** | 依序生成熱震、凍結與感電，最後把三種狀態捲成循環天候。 |
| 烈焰灌注 → 回聲齊射 → 風暴充能 | **流火雷音** | 火焰開路、回聲分裂、雷擊處決；形成向前旋轉的三層攻擊。 |
| 霜爆灌注 → 劇毒刃 → 烈焰灌注 | **霜蘭流火** | 冰封保存毒層，火焰碎冰時一次釋放；死亡區域長出兼具傷害與治療的腐花。 |
| 治癒之光 → 復甦之靈 → 翠綠復甦 | **春庭載陽** | 光、靈與自然形成三層治療陣，依序淨化、治療、轉化溢補護盾。 |
| 血之契約 → 治癒之光 → 復甦之靈 | **同脈來復** | 先以血契承擔傷害，再由慈光與復甦之靈返還生命；低血目標得到更高回復。 |
| 鋼鐵意志 → 血之契約 → 反擊守勢 | **守一共脈** | 承受傷害時不退，將吸血與反擊綁定；反擊傷害同時治療最低生命友方。 |
| 疾風步 → 橫掃延伸 → 巨型弧斬 | **扶搖月輪** | 高速繞場留下圓形斬線，最後以巨弧從圓心向外切開。 |
| 奧術吐息 → 風暴充能 → 回聲齊射 | **綿息雷音** | 以 AP 星脈供能雷陣，每枚回聲彈都成為一次雷擊落點。 |

## 實作邊界

| 項目 | 規則 |
|---|---|
| Combo 名稱 | 維持直觀功能名，不套用古籍詞根，不因終結技命名而改名 |
| 終結技名稱 | 使用現代暗黑奇幻與戰鬥遊戲語彙，必須與觸發 Combo 的實際效果相符 |
| 配方判定 | 精確記錄最近三張符合資格的卡，順序必須完全一致 |
| 同卡覆蓋 | 20 張表內招式全部具備 `同卡 ×3` 配方 |
| 優先級 | 跨卡精確配方優先於同 Family 泛用配方；同卡 ×3 不被泛用配方覆蓋 |
| 效果繼承 | 讀取卡片等級、Combo 五次升級、裝備與 Blessing mutation |
| 防禦／治療 | 可產生非傷害終結技，不能強迫轉成攻擊型效果 |
| UI | 第 1、2 張後顯示可能配方；第 3 張只顯示實際觸發名稱 |
| Runtime 狀態 | 本文件尚未實作，不能把 32 個規劃配方寫成現行功能 |
