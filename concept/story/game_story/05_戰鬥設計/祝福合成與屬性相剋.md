# 祝福、祝福合成與屬性相剋

## 祝福的世界觀

祝福是意念被希望放大後，在一次遠征中形成的法則。天界稱它神賜，地界稱它烙印，人界稱它祝福；系統上屬於同一種力量。

## 現行祝福規則

- 只存在於當次遠征，遠征結束重置。
- 同一祝福再次取得會升級，最高 Lv.3。
- 兩個 Lv.3 基礎祝福可合成一個 Lv.1 進化祝福。
- 進化祝福保留雙方部分效果與終結技 mutation，並能再次升至 Lv.3。

| 祝福 | 屬性 | Lv.1→Lv.3 方向 | 終結技變化 |
|---|---|---|---|
| Infernal Grace | 火 | Combo 共鳴與倍率 | 燃燒、最終爆炸 |
| Echoing Will | 暗 | Combo 效果與倍率 | 衰減迴響 |
| Venomous Font | 毒 | Combo 返 AP、終結技治療 | 中毒、死亡擴散 |
| Thunder Oath | 雷 | 元素傷害 | 暈眩、連鎖雷擊 |
| Celestial Momentum | 風 | 速度、終結技尺寸 | 穿透、高速化 |
| Absolute Zero | 冰 | Combo 疊層上限 | 冰緩、凍結、碎裂 |

建議補齊水「潮汐記憶」、光「未書慈悲」、普通「凡人決意」。Lv.1 要定義 Build；Lv.2 加入跨卡互動；Lv.3 改變終結技形態。合成後 Lv.2 出現雙屬性反應，Lv.3 取得獨有稱號與大型演出。

## 祝福合成例

| 雙 Lv.3 | 進化名稱 | 新機制 |
|---|---|---|
| 火＋風 | 焚天疾誓 | 移動火風暴吸入敵人後爆散 |
| 火＋冰 | 霜燼悖論 | 凍結後由內燃爆，同目標有冷卻 |
| 雷＋水 | 天河導體 | 水痕連線，雷擊沿線跳躍 |
| 毒＋暗 | 無聲瘟夜 | 咒痕到期擴毒，死亡留下影分身 |
| 光＋暗 | 自由蝕環 | 抵銷敵我法則，玩家選治療或處決 |
| 普通＋元素 | 人間鍛印 | 犧牲元素倍率，強化破韌與王權抗性 |

中篇會揭露祝福也可能把人固定成某種角色；雙王戰後，祝福 UI 的「賜予者」改成「見證者」，表示力量來自選擇而非王權。

## 屬性相剋提案

現行只有九屬性的分類與顏色，以下倍率尚未實作。建議採三組易記關係：

- 水 → 火 → 冰 → 水。
- 風 → 毒 → 雷 → 風。
- 光 ↔ 暗，雙向克制且彼此高風險。
- 普通不克制也不被克制，專長是破韌與法則護甲。

建議倍率：克制 1.25、被克制 0.80、同屬 0.90、普通 1.00。

| 屬性 | 基礎狀態 | 二次反應 |
|---|---|---|
| 水 | 潮濕 | 水＋雷連鎖感電；水＋冰範圍凍結 |
| 火 | 燃燒 | 火＋風擴張；火＋冰熱震碎裂 |
| 冰 | 霜緩 | 疊滿凍結，重擊造成碎裂 |
| 風 | 失衡 | 強化推拉並擴散火、毒 |
| 雷 | 感電 | 潮濕敵人間跳躍 |
| 毒 | 腐化 | 降治療／護甲；暗＋毒死亡擴散 |
| 光 | 顯形 | 驅散隱身；治療溢出轉盾 |
| 暗 | 咒痕 | 延遲傷害；光暗蝕解移除增益與減益 |
| 普通 | 破韌 | 破除姿態和王權法則護甲 |

天堂宣稱光克一切，地界宣稱暗吞一切；實際上兩者互相傷害，而普通人的意志能破除兩方的所有權。主角不是萬能的第十屬性，而是能讓不同靈魂短暫合作、快速換屬。
