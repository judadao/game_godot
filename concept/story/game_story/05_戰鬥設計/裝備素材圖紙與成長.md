## 裝備 Lv.1–Lv.15 成長規則

裝備的正式設計上限為 **Lv.15**。一般等級提供穩定數值成長；每 3 等發生一次「小躍進」，每 5 等發生一次「大躍進」。Lv.15 同時落在 3 與 5 的節點，但不重複給兩次效果，而是合併為最強的「最終覺醒」。

> 實作註記：目前 runtime 只支援 Lv.1–Lv.3。現行成本為 Lv.1→2：25 Gold、5 Autumn Wood、2 Magic Shard；Lv.2→3：50 Gold、10 Autumn Wood、4 Magic Shard。Lv.4–Lv.15、突破素材與逐級效果仍待實作。

### 成長節點

| 等級 | 階段 | 成長內容 |
|---|---|---|
| Lv.1 | 鍛造成形 | 基礎能力與第一個流派被動 |
| Lv.2 | 基礎強化 | 提高主要數值 |
| Lv.3 | 小躍進 I | 被動開始與一個 Combo family 互動，外觀出現第一道魂紋 |
| Lv.4 | 穩定強化 | 提高副屬性或縮短能力冷卻 |
| Lv.5 | 大躍進 I・共鳴 | 解鎖第二被動；武器靈魂第一次清楚說話，外觀產生明顯變化 |
| Lv.6 | 小躍進 II | 強化 Combo 觸發條件或擴大作用範圍 |
| Lv.7–8 | 精鍊 | 提升基礎數值、狀態效率與流派穩定度 |
| Lv.9 | 小躍進 III | 解鎖一項條件式戰鬥機制，例如追擊、反擊或殘影 |
| Lv.10 | 大躍進 II・真名 | 取得兵器真名；特殊能力產生質變，開始需要 Boss 核心與角色劇情 |
| Lv.11 | 真名精鍊 | 強化真名能力的可用頻率 |
| Lv.12 | 小躍進 IV | 真名能力與具名終結技產生聯動 |
| Lv.13–14 | 極限鍛造 | 成本劇增；需要雙界高階素材與特殊挑戰證明 |
| Lv.15 | 最終大躍進・覺醒 | 裝備完全覺醒，獲得足以改變 Build 規則的終極能力與專屬演出 |

### 難度曲線

- Lv.1–Lv.5：前篇可穩定培養，讓玩家完成第一套 Build。
- Lv.6–Lv.9：需要菁英素材、工坊升級與對應 Combo 熟練度。
- Lv.10：第一道真正門檻，必須取得特殊王核心並完成裝備的真名事件。
- Lv.11–Lv.12：需要天堂或地界的高階材料，不能只靠商店購買。
- Lv.13–Lv.14：極困難；需要特殊破招掉落、角色羈絆完成及高難度遠征證明。
- Lv.15：全遊戲最難的永久成長之一。除最終王級素材外，還必須完成兵器靈魂的願望；不能單靠刷素材達成。

### 躍進原則

- 一般升級加數值；躍進必須改變玩法或觸發方式。
- 小躍進負責讓 Build 更順、更專精；大躍進負責開啟新能力。
- Lv.10 之後，每次成長都要有可見外觀變化，不能只有面板數值。
- Lv.15 很強，但不是無條件全能；它應把單一流派推到極致，仍保留被其他 Build 克制的可能。

## 圖紙解鎖條件

1. **城鎮基礎圖紙**：依希望火炬 Tier 逐步進貨。
2. **角色研究圖紙**：完成 NPC 羈絆才開放，不直接販售。
3. **Boss 殘缺圖紙**：Boss 掉關鍵頁，回城找指定 NPC 解讀。
4. **抉擇圖紙**：完成價值選擇才定型；不同選擇改變能力，不只分好壞。
5. **王權圖紙**：雙王戰後取得，製作時必須放棄一項象徵權力。
