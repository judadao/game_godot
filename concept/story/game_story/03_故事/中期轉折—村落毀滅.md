# 中期轉折：內側破口與 Town 毀滅

## 正式因果

```text
天律院利用聖女的接引祈禱
→ 天界取得封印內側座標
→ 地界利用女巫的祕密聯絡與灰印
→ 地界取得另一條內側道路
→ 兩界首次越過傳送門進入 Town
→ 聖女與女巫公開道歉並協助居民避難
→ Town 毀滅、希望之火幾近熄滅
→ 天地幹部揭露主角是惡鬼與亡魂的聚合體
→ 惡鬼力量覺醒，主角消滅兩名幹部
→ 亡魂情緒反噬，主角立下復仇誓言
→ 第四章殺入地獄，逐步把仇恨轉化為寬恕與希望
```

## 兩人的責任

- 聖女並非想傷害 Town。她相信天界最高機構能阻止出兵，因此以自己的聖女權限開啟接引祈禱。
- 女巫已開始偏向 Town，卻仍隱瞞身分、私下處理地界情報，因此獨自使用對方交付的灰印。
- 兩人都遭到利用，也都確實做出了造成破口的選擇。劇情不以「她們也是受害者」取消責任。
- 發現真相後，兩人不逃跑、不要求立刻獲得原諒，而是公開道歉並留下協助撤離。

## 主角的覺醒

主角不是取回個人童年，而是得知自己根本沒有出生前的單一人生。他由戰場上無數惡鬼與亡魂聚合而成；鍛造技藝、劍魂感知與戰鬥本能都來自亡者的程序記憶。

Town 中逐漸形成的開朗性格、選擇與人際關係，才是只屬於主角自己的部分。

惡鬼力量讓他消滅天地幹部，也把所有亡者的憤怒、不滿、難過與後悔灌進意識。第三章結束時，他尚未放下仇恨，並明確決心復仇。

第四章才完成轉化：主角承認傷害發生過，卻不再讓復仇決定亡者與自己的未來，最終把憤怒轉化為寬恕與希望。
