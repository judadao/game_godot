# 中期轉折：村落毀滅

> [!tip] 完整提案
> 待決項目的第一版完整劇情見 [[提案/中期轉折提案A—灰燼中的決斷]]。目前仍是提案，確認後才同步為正式版本。

## 篇章定位

這是主線由「被動防守」轉向「主動反攻」的中期轉折。

前半段，主角不斷透過傳送門迎擊天界與地界派出的部隊，希望把戰火擋在 Town 之外。但敵方最終突破防線，摧毀村子，所有重要之人都在襲擊中受傷。

## 事件流程

```text
天界或地界發動中期大規模攻勢
  → 既有傳送門防線被突破
  → Town 遭到毀滅性攻擊
  → 所有重要 NPC 受傷
  → 主角產生劇烈情緒波動
  → 戰場亡魂聚合而成的惡鬼記憶覺醒
  → 主角以失控或接近失控的力量擊退中期 Boss
  → 勝利後遭到力量反噬
  → 主角反思：還要繼續這樣被動挨打嗎？
  → 重要 NPC 分別前來與主角交談
  → 主角作出最後決斷
  → 主線從村落防衛轉為向地獄與天堂主動反攻
```

## 村落毀滅

敵方此次攻勢成功突破主角過去使用的防衛方式。Town 的建築、生活空間與防護遭到嚴重破壞，重要 NPC 全部受傷。

這場毀滅不是為了否定玩家前半段的努力，而是證明只攔截敵方一次次派出的部隊，無法終止攻擊村子的根本原因。只要當權者仍能決定何時、派誰、從哪裡進攻，Town 就永遠只能等待下一次災難。

## 惡鬼記憶覺醒

看見自己珍視的人全部受傷後，主角的情緒劇烈波動，喚醒構成他的戰場亡魂所留下的「惡鬼記憶」。

這些不是主角曾經度過的個人童年或人生，而是無數亡者在戰場上留下的死亡、痛苦、憎恨與復仇記憶。主角第一次真正感受到自己為何被稱為復仇亡靈。

覺醒讓主角獲得足以擊退中期 Boss 的力量，卻也使他接近被集體仇恨吞噬。Boss 被擊退不代表主角真正勝利；這場戰鬥迫使他看見自己若只依靠憤怒，最終可能變成另一個傷害所愛之人的存在。

## 中期 Boss

- 所屬陣營：待定
- 身分／階級：天界或地界負責此次總攻的高階幹部
- 攻擊村子的理由：待定
- 對希望的立場：待定
- 是否知道主角真身：待定
- 被擊退後的生死與後續作用：待定

中期 Boss 的責任是親手證明舊防衛策略已經失效，並成為主角第一次喚醒惡鬼記憶的直接壓力。

## 戰後反思

主角看著被摧毀的家與受傷的居民，開始質問自己：

> 「還要繼續這樣被動挨打嗎？」

他意識到，只要自己仍然只是在傳送門另一端等待敵方出招，天界與地界就能不斷派出更強的士兵與幹部。即使主角每次都獲勝，也無法保證下一次沒有人受傷。

## 重要 NPC 的談話

每名重要 NPC 都會在戰後來找主角。他們不是替主角作決定，而是分別讓他看見自己正在守護什麼，以及主動反攻可能付出的代價。

### 聖女祭司：人性與希望

[[02_角色與勢力/角色/聖女祭司]]看見主角的惡鬼力量後仍然選擇相信他。她提醒主角，讓他成為人的不是身世，而是每一次選擇伸手保護別人的行動。

### 神秘女巫：真相與代價

[[02_角色與勢力/角色/神秘女巫]]知道主角若決定反攻，將真正踏入天界、地界與幕後黑手控制的領域。她必須決定還要隱瞞多少真相，也警告主角不能把守護變成沒有終點的復仇。

### 瘋狂科學家：可能性與自我

[[02_角色與勢力/角色/瘋狂科學家]]不把主角視為怪物，而把惡鬼覺醒當成一種需要理解、控制與重新定義的力量。他讓主角看見：構成方式可以解釋他的能力，卻不能決定他要成為誰。

### 城鎮守衛：責任與共同承擔

[[02_角色與勢力/角色/城鎮守衛]]承認原本的防衛方式失敗，但不允許主角把村落毀滅全部視為自己的責任。他理解主角想主動出擊，也要求主角記住，守護不是獨自送死，而是為了活著回到大家身邊。

### 商店店長：家與所愛之人

[[02_角色與勢力/角色/商店店長]]讓主角明白，家不等於完好無損的房屋。只要居民還活著、仍願意重建，這裡就是主角能回來的地方。他也把實際物資交給主角，以一貫的交易口吻支持主角的選擇。

## 主角的最後決斷

經過所有人的談話後，主角決定不再只是等待下一波攻擊。

> 他要殺穿地獄與天堂。
>
> 為了守護他的家，為了保護他愛的人。

這不是加入人界、向另外兩界宣戰，也不是讓惡鬼的復仇意念接管自己。主角仍然不屬於任何陣營；他以自己的意志決定主動攻入維持舊秩序的勢力核心，讓天界與地界失去繼續傷害 Town 的能力。

## 主線結構的改變

| 中期以前 | 中期以後 |
|---|---|
| 等待敵方攻勢情報 | 主動尋找敵方權力核心 |
| 穿越傳送門攔截軍隊 | 穿越傳送門深入天堂與地獄 |
| 擊敗負責單次攻勢的幹部 | 摧毀能持續發動戰爭的結構 |
| 保護 Town 不受傷害 | 為受傷的家人終結威脅 |
| 尚未理解惡鬼本質 | 學習控制並超越惡鬼記憶 |
