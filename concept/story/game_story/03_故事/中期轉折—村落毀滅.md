# 中期轉折：正史碎裂與 Town 毀滅

> [!warning] 非舊提案版本
> [[提案/中期轉折提案A—灰燼中的決斷]] 已明確未採用。本頁依正式主線整理。

## 正式因果

```text
天堂記錄官改寫主角歷史
→ 正史英雄取代主角
→ 希望把居民固定成完美角色
→ 居民以不完美的小事找回真正主角
→ 主角擊敗正史英雄、斬碎唯一正史
→ 多重矛盾歷史同時坍塌
→ Town 毀滅、所有重要 NPC 受傷
→ 主角惡鬼記憶覺醒，擊退記錄官與殘餘攻勢
→ 五名 NPC 分別談話
→ 主角決定先入地獄釋放亡魂，再上天堂打破唯一未來
```

## 中期敵人

- 正史英雄：天堂用希望與記錄製造的「合法主角」，也是主角最渴望接受的虛假答案。
- 天律記錄官：執行正史改寫的天界高階幹部；Town 坍塌時是惡鬼覺醒直接擊退的對象。
- 中期災難不是某一名 Boss 單純炸毀 Town，而是主角斬碎唯一正史後，多重歷史與敵方攻勢一起失控。

## 主角的決斷

主角不是為了復仇而消滅所有天界與地界居民。他要主動摧毀能不斷製造戰爭、擁有亡魂、決定未來的兩個王權核心。

> 「我不是去替仇恨找一個王。」
>
> 「我要讓王再也不能決定誰該被犧牲。」
