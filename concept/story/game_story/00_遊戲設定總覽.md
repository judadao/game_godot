# 遊戲設定總覽

> [!important] 文件規則
> 先讀 [[00_正史與文件權威]]；正式故事以 [[03_故事/完整主線—無名之火]] 為準。

## 一句話核心

玩家扮演一名由三方戰場亡魂與戰爭因果聚合而成、沒有父母與記憶的開朗旅人；他在 Town 學會人性，拒絕地獄以復仇擁有亡者，也拒絕天堂以幸福奪走自由，最後把希望與選擇未來的權利散播世界。

## 四個支柱

1. **三界不是善惡二分**：天堂與地獄是政權，不代表天界與地界所有生命。
2. **希望放大選擇**：它既能強化守護，也能強化控制，因此不能被任何王獨占。
3. **亡魂學會做人**：主角的過去屬於許多亡者，但現在由自己與 Town 居民共同創造。
4. **鍛造即敘事**：Combo 是靈魂意志，裝備進化是持有者與器魂共同作出的選擇。

## 主線結構

```text
Town 日常與傳送門遠征
→ 天堂正史改寫、正史英雄取代主角
→ 居民找回不完美記憶、Town 因歷史坍塌被毀
→ 主角決定主動反攻
→ 地獄王：釋放亡魂與復仇所有權
→ 天堂王：拒絕完美未來與唯一答案
→ 希望散播、主角成為凡人並回 Town 打鐵
```

## 玩家幻想

- 聽見武器與歷史中被忽略的聲音。
- 以 Combo、祝福、裝備詞條組合自己的戰鬥語言。
- 把 NPC 羈絆轉化成聖騎士、大天使、禁咒、王術、機巧與因果系列。
- 面對看似美好的答案，仍親自決定要成為誰。
