# 核心角色人物聖經

## 使用方式

本頁補充角色在場景中的「反應規則」。若與個人頁衝突，以 [[00_正史與文件權威]]、正式主線及本頁較新的核心描述為準。

## 主角

### 內在結構

| 層次 | 內容 |
|---|---|
| 表面欲望 | 想幫上忙、想讓大家開心、想證明自己不是累贅 |
| 真正欲望 | 想被某個地方自然地算進「我們」裡，不需要先證明來歷 |
| 最大恐懼 | 自己的開朗只是亡魂拼出的假面；一旦停下來就只剩仇恨 |
| 錯誤信念 | 只要自己夠強、先替所有人擋下危險，就不會再失去家 |
| 必須學會 | 被愛不是因為有用；守護也包括讓別人共同承擔 |

### 日常細節

- 不知道生日，所以會把第一次進 Town 的日子稱作「被守衛攔下紀念日」。
- 睡覺不會把劍放在床邊，而是靠在門旁，因為他覺得劍魂也需要自己的位置。
- 吃到喜歡的東西會立刻想分人，分完才發現自己沒有留下。
- 對貨幣與物價毫無概念；但碰到爐火與工具後，亡魂工匠記憶會讓他準確辨認金屬與火候。之後他仍保留每一塊由自己新手法敲壞的鐵，分清哪些是借來的記憶、哪些是這段人生的練習。
- 害怕安靜。在鐵匠鋪獨處時會敲兩下鐵、哼歌或和劍魂說話。
- 記不住正式稱謂，會替人取出自認親切、實際很失禮的短稱。

### 說謊、失態與道歉

- **說謊方式**：笑得更大聲，立刻轉去幫別人，回答「我沒事啊」。
- **失態徵兆**：突然不說「我們」，只說「我來處理」；不再詢問武器裡的靈魂是否願意。
- **真正發怒**：音量反而降低，句子變短，周圍武器同時震動。
- **道歉方式**：不擅長解釋，會先把弄壞的東西修好，再坐在附近等對方願意說話。

### 關係稱呼變化

- 初識：「祭司小姐」「女巫小姐」「科學家」「守衛大哥／大姐」「店長」。
- 熟悉後：直接叫職稱，語氣像家人；緊張時才恢復客氣全稱。
- 正史危機中：當他不確定大家是否還認識自己，會刻意不叫名字，避免聽見對方否認。
- 結局後：成為凡人後第一次主動說「我回來了」，不再問自己能不能留下。

## 聖女祭司

### 內在結構

| 層次 | 內容 |
|---|---|
| 表面欲望 | 治好所有人，讓任何人都不被放棄 |
| 真正欲望 | 即使沒有神諭，她的選擇也仍值得相信 |
| 最大恐懼 | 大天使的力量與善意其實在借她的手控制別人 |
| 錯誤信念 | 慈悲就是永遠答應、永遠原諒、永遠替別人承受 |
| 必須學會 | 拒絕、界線與讓對方承擔後果，也可以是慈悲 |

### 日常細節

- 在食物上畫祝福符號，畫完才想起那塊麵包要切給大家。
- 怕黑但不承認；夜巡時會用「檢查燭台」為理由跟著守衛。
- 記得每名居民的舊傷，卻常忘記自己有沒有吃飯。
- 生氣時會把人的全名和職稱說得非常完整。
- 不會做菜，卻會把每次失敗配方仔細寫下，堅稱這叫排除法。

### 說謊、失態與道歉

- **說謊方式**：雙手交握，引用不存在或非常偏門的經文。
- **失態徵兆**：連續問「你還好嗎」，其實是在確認自己是否仍有用。
- **真正發怒**：不提高聲音，而是下達非常清楚、不容討價還價的命令。
- **道歉方式**：承認自己替對方做了決定，接著詢問「現在你希望我怎麼做」。

### 毀城後變化

手與聲帶受傷後，她不能長時間祈禱或施法。她開始用手勢指揮救護，把「神會保護你」改成「我在這裡，但選擇是你的」。大天使系列的成立點不是恢復神術，而是她拒絕成為大天使容器。

## 神秘女巫

### 內在結構

| 層次 | 內容 |
|---|---|
| 表面欲望 | 讓所有危機維持在自己可控制的範圍 |
| 真正欲望 | 有人知道全部真相後，仍願意把她當作 Town 的居民 |
| 最大恐懼 | 她一旦坦白，Town 與地界旁系王室的倖存者必須互相犧牲 |
| 錯誤信念 | 只要秘密由她一個人承受，別人就不必做痛苦選擇 |
| 必須學會 | 替別人隱瞞選項也是一種控制；信任包括允許別人承擔真相 |

### 日常細節

- 房間裡每個瓶子都貼錯標籤，真正分類方式是瓶塞顏色與擺放角度。
- 喜歡甜食，但購買時一定搭配三種苦藥材作掩護。
- 知道所有捷徑，卻故意走最遠的路，藉此觀察有沒有人跟蹤。
- 會替流浪貓取王室過去政敵的名字。
- 對主角說「別碰」通常代表真的危險；說「隨便你」才代表她很在意。

### 說謊、失態與道歉

- **說謊方式**：說的每一句都是真的，但故意刪掉能改變結論的那一句。
- **失態徵兆**：不再諷刺，開始反覆整理袖口或確認逃生路線。
- **真正發怒**：直接叫出對方真名；對主角則會說「你不是他們」，阻止亡魂接管。
- **道歉方式**：先交出一項能傷害自己的情報或信物，再說出沒有修飾的完整句子。

### 王室身分細節

她不是等待復位的公主。她保留王術，是為了拆除「王族才能命令亡魂」的規則。她最厭惡別人向她跪下；第一次看見主角開玩笑行禮時，她反應過度，之後才勉強解釋原因。

## 瘋狂科學家

### 內在結構

| 層次 | 內容 |
|---|---|
| 表面欲望 | 理解所有未知現象，做出誰都沒見過的裝置 |
| 真正欲望 | 即使實驗失敗、幫不上忙，朋友也不會把自己趕走 |
| 最大恐懼 | 自己終有一天會因好奇傷害最想保護的人 |
| 錯誤信念 | 只要收集足夠數據，所有情感和風險都能先被解決 |
| 必須學會 | 無法預測不等於不負責；承認害怕也是研究的一部分 |

### 日常細節

- 實驗紀錄極整齊，生活區卻亂到只有自己知道落腳點。
- 替每次爆炸編號，不叫失敗，叫「快速拆卸事件」。
- 吃東西會計算最佳入口角度，最後因講解太久讓食物冷掉。
- 不會安慰人，會默默留下修好的物品、暖手裝置或噪音很大的助眠器。
- 對主角的靈魂結構非常好奇，但在取得同意前只研究主角帶回的劍，不直接檢查本人。

### 說謊、失態與道歉

- **說謊方式**：快速報出大量無關數據，讓人忘記原本問題。
- **失態徵兆**：停止記錄；真正害怕時會把筆放下，反覆檢查朋友呼吸。
- **真正發怒**：把對方稱為「不可接受的變數」，並開始極冷靜地拆解其系統。
- **道歉方式**：完整列出自己錯在哪、造成什麼後果與修正方案，最後很小聲補一句「我不是只在乎實驗」。

## 城鎮守衛

### 內在結構

| 層次 | 內容 |
|---|---|
| 表面欲望 | 讓 Town 每一天都平安照常開始 |
| 真正欲望 | 有一天能卸下盔甲，而不覺得自己背叛死去的同袍 |
| 最大恐懼 | 一次錯誤信任會害死居民；一次不信任也會把無辜者推成敵人 |
| 錯誤信念 | 責任是最可靠的人永遠站第一個、最後一個離開 |
| 必須學會 | 防線不是一個人，而是一群願意換班的人 |

### 日常細節

- 巡邏時會扶正歪掉的招牌，從不承認是自己做的。
- 記得所有孩子會躲在哪裡，假裝那只是安全勤務需要。
- 武器保養非常仔細，但仍拒絕換掉使用十年的舊劍。
- 喝醉後不會話多，只會開始稱讚每個人的工作，隔天全不承認。
- 對主角說「準時回來」比「小心」更重要，因為那代表已替他留了位置。

### 說謊、失態與道歉

- **說謊方式**：說「這是命令」掩飾私人關心。
- **失態徵兆**：開始重複檢查同一道門閂，或把所有責任往自己身上收。
- **真正發怒**：先把無關居民撤走，再在只剩當事人時爆發。
- **道歉方式**：主動把自己的武器交給對方保管，表示暫時放下權威。

## 商店店長

### 內在結構

| 層次 | 內容 |
|---|---|
| 表面欲望 | 讓商店有盈餘、貨架不空、每筆帳都對得上 |
| 真正欲望 | 確保任何人陷入困難時，都有一條不必求神或求王的退路 |
| 最大恐懼 | 資源不足時必須親手決定誰能得到藥、誰只能等待 |
| 錯誤信念 | 關心若說出口就會變成無法兌現的承諾，最好包裝成交易 |
| 必須學會 | 家人不是欠款人；讓別人回報關心不代表失去掌控 |

### 日常細節

- 公開帳本記金錢，暗帳記誰需要鞋、藥、工作或一頓不被追問的晚餐。
- 會故意把即期食物說成「試吃品」，讓自尊心強的人願意拿走。
- 最討厭討價還價，卻會在主角離開後把差額偷偷塞回袋底。
- 知道女巫材料的用途、科學家欠款不可能還完，選擇只問能避免事故的部分。
- 店門關閉後才允許自己露出疲倦；主角若撞見，他會立刻派搬貨工作轉移注意。

### 說謊、失態與道歉

- **說謊方式**：把贈送說成庫存錯誤、折扣、抵押或預付款。
- **失態徵兆**：算錯最簡單的加法，或沒有注意到客人拿走東西。
- **真正發怒**：取消所有客套，直接說出對方真正害怕失去什麼。
- **道歉方式**：撕掉一頁欠款，承認那從來不是債，再請對方留下吃飯。

## 六人互補

| 情境 | 第一反應 | 最後真正需要做的事 |
|---|---|---|
| 有人受傷 | 主角衝、聖女救、守衛封鎖、科學家分析、女巫隱瞞危險、店長補給 | 彼此交換資訊，不讓一人承擔全部 |
| 真相出現 | 主角直接問、聖女尋求意義、女巫刪減、科學家驗證、守衛評估風險、店長問代價 | 接受沒有人擁有完整答案 |
| Town 毀滅 | 六人都先說自己能做什麼 | 六人承認自己也需要幫助 |
