# 希望之火

希望是放大「意念與選擇」的力量，不是自動帶來幸福的善性能源。它能強化守護、勇氣與慈悲，也能強化復仇、控制與恐懼。

```text
希望 → 放大意念 → 意念改變能力與現實
```

## 最後火種

過去戰爭中，各地火種陸續被政權收編、固定成神賜或烙印，失去自由回應不同生命的能力。Town 保存的是最後一團未被單一法則命名的火。

## 式微原因

瘴氣是外在壓力；更深原因是天堂與地獄以正史、所有權與恐懼壓縮 Town 的選擇。當居民相信未來只剩被接管或摧毀，希望便失去燃料。

## 代價

- 希望不能替人選擇，只能放大既有意念。
- 矛盾意念可能造成力量失控、歷史重疊或人格固定。
- 集中希望會創造新王權，因此主角最終放棄獨占。
- 散播希望也會釋放惡意；結局給世界的是自由與責任，不是永久和平。

祝福是短期放大的法則，裝備躍進是器魂與持有者共同意念形成的長期能力。最終主角散播希望、失去神性但保留人格，詳見 [[03_故事/最終結局—希望散播]]。
