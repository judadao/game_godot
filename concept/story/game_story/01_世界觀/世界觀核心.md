# 世界觀核心

## 三條世界規則

1. **靈魂會留下意志**：強烈死亡、承諾與未竟之願能停留在武器、場所與記錄中。
2. **希望會放大意念**：它不判斷善惡，只讓選擇更有改變現實的力量；越想把希望固定成唯一答案，越會奪走他人自由。
3. **記錄能塑造現實，但不能完全消滅生活痕跡**：天堂能改寫正史，卻無法預先創造無人記錄、不完美又真實的小事。

## 世界結構

- 天界、地界、人界是可透過傳送門跨越的實際界域，也各有不同靈魂法則。
- 天堂與地獄是天界、地界的統治政權，不等於該界所有居民。
- 兩個政權都在人界扶植附屬國家、領地與軍隊，長期將人界作為代理戰場。
- 目前名義休戰，實際仍有局部攻勢、情報戰與代理衝突。

## 力量在世界中的名稱

| 系統 | 世界內解釋 |
|---|---|
| 普通攻擊 | 武器本身的戰鬥方式 |
| Combo 卡 | 主角將一段靈魂意志暫時鍛入動作 |
| 具名終結技 | 多段意志形成可重現的完整戰技記憶 |
| 祝福／神賜／烙印 | 希望放大的短期法則；名稱依陣營而異 |
| 裝備進化 | 持有者與器魂共同累積的經歷與選擇 |
| 屬性 | 靈魂與環境呈現力量的性質，不代表善惡陣營 |

## 當前失衡

地界瘴氣蔓延，希望火炬式微。天堂與地獄都害怕希望落入對方手中，也都在觀察戰爭因果形成的主角會成為誰。Town 因此同時是戰略目標、人格實驗場與最後中立聖地。

## 真相分層

| 層級 | 所知版本 |
|---|---|
| 一般居民 | 三界休戰，Town 因古老結界而安全 |
| 少數守護者 | Town 保存希望，受大天使與地界旁系王室共同保護 |
| 天堂／地獄高層 | Town 可能孕生不受分類的因果存在，不能讓對方取得 |
| 最終真相 | 希望不屬於王權；主角與眾生都能選擇力量的意義 |
