# Main Horizontal Town Concept

This folder stores full-width town concept/reference images only.

These files are not sliced runtime assets. Use `concept/town/can_use/` for Godot-ready prototype PNGs.

- `town_panorama_concept_v1.png`: 2172x724
- `town_panorama_concept_v2.png`: 2172x724

## Rules

- Keep complete horizontal town concepts here.
- Treat `town_style_direction_a_locked.png` as the current Town background direction;
  runtime uses derived modular assets and must not bake its buildings or banners back in.
- Do not put cropped runtime sprites in this folder.
- Move approved slices into `concept/town/can_use/<category>/` with manifest metadata.
- Treat all current concepts as `internal_prototype_only` until final art/license review.
