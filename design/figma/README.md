# Figma Design Assets

All map-specific Figma sources, previews, component studies, and approved exports
live under:

```text
design/figma/<map_id>/
```

Current map folders:

- `town`
- `autumn_battle`
- `autumn_tree`
- `crystal_caves`
- `forbidden_graveyard`

Keep editable labels and hotspot overlays in Figma/SVG layers. Do not bake
localized text into raster background art. Runtime-imported production sprites
remain under `assets/`; this directory owns design sources and review exports.
