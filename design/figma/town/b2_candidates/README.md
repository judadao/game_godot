# Town B2 Building and Landmark Candidates

這個資料夾只保存 Figma 審稿用的透明 PNG，尚未接入 runtime。

共同生成規格：

- B2 手繪粗顆粒 pixel art，避免銳利向量感。
- 正面為主，只露窄右側面；深度線往右上後退。
- 垂直柱保持垂直，地基保持水平。
- 左上暖光、冷紫褐陰影、局部琥珀窗光。
- 每張只含一個完整物件，不含人物、背景、文字、旗幟或街景。
- 建築功能靠輪廓與整合在建築內的設備辨識，不靠文字標籤。

候選清單：

| --- | --- |

| `player_forge_b2.png` | 主角鐵匠鋪；整合式鍛造拱與鐵砧 |
| `town_hall_b2.png` | 村長家；鐘樓、雙門與藍色布章 |
| `sword_soul_shop_b2.png` | 劍魂商；劍形識別與小型藍紫魂火 |

| `eternal_flame_b2.png` | 獨立不滅火炬石塔 |
| `battle_portal_b2.png` | 獨立石拱與藍紫旋渦 |
