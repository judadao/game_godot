# Curated assets from `game_own`

These assets were reviewed and copied from `D:\game\game_own`. Original pack
folders and license files are preserved. Godot `.import` cache files were not
copied; Godot will generate fresh imports for this project.

## Included

- `world/legacy_fantasy/`: detailed fantasy terrain, buildings, trees,
  characters, and creature animation sheets. See `TERMS.pdf`.
- `town/opp_village/`: polished pixel-art village buildings, backgrounds, and
  reference mockups. CC0; see `license cc0 - public domain.txt`.
- `items/oga_rpg_item_icons/`: illustrated RPG equipment, crafting, potion,
  spell, and item icons. CC0; see `LICENSE.md`.
- `ui/oga_parchment_gui/`: parchment panels, buttons, labels, and slots. See
  `LICENSE.md`.

## Excluded

- `ninja_adventure`: very small and visually simpler than the current project.
- `kenney_pixel_platformer`, `kenney_platformer_buildings`, and
  `kenney_foliage_pack`: clean but too minimal and stylistically inconsistent.
- `kenney_pixel_ui`: redundant with the stronger parchment and existing UI.
- Engine, Git, plugin logos, add-on artwork, imported caches, and project
  implementation files.

## Suggested use

- Town exteriors: start with `town/opp_village/environment/`.
- World tiles and props: start with `world/legacy_fantasy/Assets/`.
- Inventory and loot UI: use `items/oga_rpg_item_icons/`.
- Dialog and inventory frames: use `ui/oga_parchment_gui/`.
