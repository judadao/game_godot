# Autumn Combat Card Icons

These four 256×256 PNG assets are the authored semantic icons for the fixed
Autumn Combat hand:

- `healing_light.png`: green healing light and restorative leaf energy.
- `flame_imbue.png`: orange flame infusion and empowered weapon energy.
- `echo_volley.png`: violet multi-projectile volley.
- `storm_charge.png`: cyan lightning charge and storm mobility.

They were created with OpenAI's built-in image generation on 2026-07-30 from
the approved Autumn HUD redesign direction, then cropped and reviewed as
text-free runtime assets. `AutumnBattleCard` owns their mapping and keeps card
names, shortcuts, type labels, level, and AP cost as live UI text.

Generation direction: polished dark-fantasy survival HUD, obsidian card
surfaces, restrained antique-gold frames, high-contrast semantic spell
silhouettes, luminous green/orange/violet/cyan families, readable at 48 px,
without baked text, letters, numerals, logos, or watermarks.
