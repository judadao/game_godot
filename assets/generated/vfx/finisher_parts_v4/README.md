# Finisher authored frame sequences v4

Each PNG is a 4-column × 3-row sheet containing twelve chronological drawings
of one name-bound semantic object. Runtime crops and displays one frame at a
time; frames never cross-fade.

Camera contract:

- Keep one horizontal ground-contact baseline at roughly 78–84% of every cell.
- Keep whole-sheet and runtime sprite rotation at zero.
- Move grounded attacks horizontally and gravity-driven objects vertically.
- Express depth only with scale, spacing, overlap and z-order.
- Use one causally traceable hero object and one climax; do not add a second
  explosion, floor slab, diagonal lane, UI, text or character.

Final review covers every source sheet at original detail, the integrated full
frames, each fixed 3-column × 2-row review slice, all 128 native stage captures,
and all 32 twelve-frame runtime motion sheets.
