# Finisher VFX Visual Matrix v1

本文件把 `data/combo_finishers.json` 的 32 個終結技轉成可實作的光影、幾何與
粒子規格。中文名、ID、role 與圖示色彩以目前 catalog 與
`res://assets/ui/finishers/generated/` 為準；既有五招 profile 只作模組拆分與節奏
基準，不沿用其中已過期的 display name。

視覺方向借用高規格日系 RPG 的「材質先辨識、三段式大招節奏、短促舞台壓暗」與
HD-2D 的「深色場景上疊發光幾何、清楚像素粒子層次」，並採電影式主光、輪廓光、
局部體積光和反打光。所有符號、輪廓與動作設計均為本專案原創；不得重現任何既有
作品的召喚陣、品牌圖形、角色剪影、鏡頭構圖或招式特有圖案。

## 共同視覺規則

- 正式元素 taxonomy 僅使用 `water / fire / wind / lightning / ice / poison /
  light / dark / normal`。名稱含山、石、庭、枝等意象時仍需投影到這九種元素，
  不新增第十種元素。
- 每招固定三段：`charge` 先給 0.12–0.28 秒可辨識 cue，`impact` 用單一主輪廓和
  2–4 frame 白熱核心確認傷害時點，`afterglow` 於 0.20–0.55 秒內讓材質碎屑、
  流向與狀態意義退場。
- 主形狀用不透明 core 保證輪廓；outer glow、體積霧與粒子只能襯托，不能用 bloom
  取代形狀。最亮值只保留給命中核心、劍刃交點或治療脈衝中心。
- 角色與主要敵人的可讀輪廓不可連續被遮住超過 0.12 秒。全螢幕暗角不得壓黑 HUD；
  大型環、幕或煙霧的中央必須留負空間。
- 粒子分成 `hero`（6–16 個可追蹤大粒子）、`support`（16–40 個中粒子）與
  `dust`（短命細屑）三層。hero 粒子不可被 support 噪點淹沒，同層不得均勻撒滿畫面。
- 幾何、粒子、光照都要服從 catalog 的實際效果：穿透採單一清楚前進軸、折返採
  去回不同軌跡、護盾採閉合輪廓、治療採由低血目標或中心向外的正向脈衝。

## 32 招視覺矩陣

### 01. 戰律希聲 (`silent_battle_rhythm`) — offense

- **Icon 主色**：古銅金、暗赤銅、象牙白；黑色負空間居中。
- **元素／材質**：`normal`；敲擊後泛紅的鍛金薄片、白熱劍壓與暗紅漆面反光。
- **幾何 motif**：三層不完整同心肋環，沿水平攻擊軸依次閉合；中央劍脊作節拍指針。
- **粒子 motif**：每擊一組短方片和細長金屬屑，第三擊將前兩組殘屑吸回交點。
- **三段節奏**：蓄力時三環無聲收窄；命中為三次由窄到寬的矩形壓力斬，末擊重疊出十字核；餘韻讓紅熱邊緣依反節拍熄滅。
- **光影重點**：低亮古銅環只吃側逆光，第三擊才以象牙白 key light 瞬間照亮目標輪廓。
- **可讀性限制**：不可畫成音符或均勻聲波；三次命中必須在空間寬度與亮度上明確遞增。

### 02. 天際流光 (`horizon_stream`) — offense

- **Icon 主色**：白金、暖象牙、淡煙灰；少量冷青邊光。
- **元素／材質**：`light + normal`；日照般白金劍光、拉絲銀與薄霧。
- **幾何 motif**：兩條超長平行地平線在遠端匯成透視消失點，第二條反向切回形成扁菱形夾角。
- **粒子 motif**：方向一致的細金屑、被吸向中線的霧帶，以及命中後橫向滑離的亮片。
- **三段節奏**：蓄力將遠景壓成一條細亮線；命中先水平貫穿再反向回切聚攏；餘韻保留一道緩慢降亮的空氣折射縫。
- **光影重點**：第一斬是冷白輪廓光，返斬改暖金反打光，交點出現短暫 lens streak 而非大圓爆炸。
- **可讀性限制**：主軸必須水平且一眼可見穿透方向；霧帶不能蓋過敵人腳下或 HUD 邊界。

### 03. 驟雨繁音 (`sudden_rain_cadence`) — offense

- **Icon 主色**：槍鐵藍、冷青白、暗金；深黑雨幕底。
- **元素／材質**：`water + normal`；鋼色雨針、濕亮鏡面與冷白斬擊火花。
- **幾何 motif**：由疏到密的斜向針線群，最後收成一枚朝前的尖長楔形。
- **粒子 motif**：短命雨針、命中位置濺起的扇形微滴、積蓄斬擊結算時的鋼藍碎屑。
- **三段節奏**：蓄力讓三束雨線逐次加速；命中以 5–7 個清楚 burst 追擊並在末拍合併成重斬；餘韻只留下向下滑落的冷光水痕。
- **光影重點**：斜上方冷 key light 掃過每次雨針，末拍用狹長白核和地面冷反光確認結算。
- **可讀性限制**：多段不可變成連續噪點；每個 burst 需有 1 frame 暗間隔，最終楔形要比前段寬一倍。

### 04. 月輪垂光 (`falling_moon_arc`) — offense

- **粒子 motif**：慢落的月塵、弧面剝離的薄片、落點向外滑行的低矮霧粒。
- **三段節奏**：蓄力在高處勾出細月弧；命中讓弧光垂直墜下切開姿態，再由圓心爆出環波；餘韻是碎月片繞半圈後向上消失。
- **光影重點**：月輪本體只亮外緣，墜落瞬間以冷白頂光切出角色剪影，環波用柔暖金收尾。
- **可讀性限制**：墜落斬與環形擊退要有上下／水平兩種清楚方向；月輪中央保持透明，不做滿屏白盤。

### 05. 千羽相應 (`thousand_blade_kill`) — offense

- **粒子 motif**：6–12 枚可追蹤 hero 羽刃、稀疏銀屑、折返點的菱形方向閃記。
- **三段節奏**：蓄力先張開左右雙翼；命中全向射出、邊界停格一拍後逐層回折；餘韻讓最後兩枚羽刃交叉穿心並化為細雪狀金屑。
- **光影重點**：去程冷銀、回程暖金，中心交叉以短促白核和環形 rim light 強調增幅。
- **可讀性限制**：不可用大量小刀填滿畫面；每枚 hero 羽刃需有獨立軌跡，折返路徑不能與去程完全重疊。

### 06. 靜岳無移 (`still_mountain`) — defense

- **Icon 主色**：炭黑、古銅、暗赭金；低飽和灰。

- **幾何 motif**：寬底窄頂的三段盾脊垂直鎖合，承傷刻痕沿盾面累積，結束時轉為貼地梯形震波。
- **粒子 motif**：受擊時僅掉落少量沉重金屬屑；結算時刻痕碎片沿地面向外跳兩次。
- **三段節奏**：蓄力由下往上扣合三層板甲；命中期維持幾乎不動，只以刻痕記錄衝擊；餘韻一次性將刻痕壓入地面並放出低矮震波。
- **光影重點**：正面保持暗，受擊點只出現短金橙側光；反擊瞬間用地面上照光刻出不可擊倒感。
- **可讀性限制**：防禦期不能持續閃爍；所有震波低於角色胸口，避免誤認為全螢幕傷害。

### 07. 石環守一 (`stone_ring_guard`) — defense

- **Icon 主色**：炭灰、鈍銀、舊金、深棕。

- **粒子 motif**：吸收時是沉重角片與短金屑；破盾後亮起的環片縮成 4–6 枚追蹤菱矢。
- **三段節奏**：蓄力讓環片由腳下升起閉合；命中期逐片承傷、局部發亮；餘韻是圓盾崩成有序追蹤碎片而非無向爆散。
- **光影重點**：環片內側有柔和冷環光，承傷片轉成暖金；追蹤時只讓前端白熱。
- **可讀性限制**：閉合輪廓不能超過角色兩倍寬；碎片必須從已亮承傷片生成，讓反射來源可理解。

- **可讀性限制**：三道軌跡高度與起終點要不同；不能使用煙塵或大片霧掩蓋穿透方向。

- **可讀性限制**：支援招不可表現成前向傷害；粒子全部朝角色或 AP 核流動，螺旋中央保持清楚。

### 15. 雷動春醒 (`thunder_prison_pierce`) — element

- **Icon 主色**：電青、冰藍、舊金、風暴黑。
- **元素／材質**：`lightning + water`；藍紫電漿、雨幕導電線與金屬雷槍。
- **幾何 motif**：四至六根垂直雷柱先形成可讀區域，柱間以稀疏折線跳躍，最後中央收束成一支水平雷槍。
- **粒子 motif**：短壽命紫藍電弧、落點的菱形電荷、雷槍尾端逆向飛散的青白針粒。

### 32. 綿息雷音 (`breathing_thunder_echo`) — hybrid

- **Icon 主色**：電藍、青白、深靛紫、舊金。
- **元素／材質**：`lightning + dark + light`；靛紫星脈、青白雷針與金色回聲節點。
- **幾何 motif**：AP 星脈先形成分枝導電網，每枚回聲彈在網上留下菱形節點，節點隨後各自垂直落雷並以細線串聯。
- **粒子 motif**：可追蹤的金色回聲珠、節點間短紫電弧、落雷後向上飛回的青白針粒。
- **三段節奏**：蓄力讓靛紫星脈從角色呼吸般收放；命中回聲彈逐枚種下節點並立即落雷；餘韻最後一雷把所有節點串成一次鏈電，再將殘餘能量回流 AP 核。
- **光影重點**：星脈只作深色導線，回聲珠用暖金定位，落雷用青白垂直 key light；鏈電收尾改紫藍背光拉開層次。
- **可讀性限制**：每個落雷必須對應可見回聲節點；同時高亮節點不超過 4 個，鏈電線不可穿過無目標空間。
