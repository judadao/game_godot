# Finisher semantic-piece specifications

This file is the compact build and review index for the 32 storyboard timelines.
Each row defines what must be spawned as separate semantic pieces, how those
pieces form and travel, what deforms at contact, and what physically remains.
The exact machine-readable values live in
`data/finisher_vfx_identities.json::choreography_profiles` and are mirrored into
each recipe's `geometry_identity`.

## Rejection rules

- Reject any result where the square source plate moves as one sprite.
- Reject recolored shared choreography, generic concentric rings, mandalas,
  radial grids, clock ticks, icon decals, or one universal center flash.
- Reject formations that already show anticipation, impact and residue at the
  same opacity. Pieces must enter in the ordered paths above.
- Reject particles that cannot be traced to a listed primitive, fracture,
  contact, fluid surface, plant surface, or ground response.
- A move passes only when its family, piece count, direction, material
  deformation and residue are recognizable without the move label.
