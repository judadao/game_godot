# Named Skill VFX Concept Bible

The production contract is `data/named_skill_vfx_profiles.json`. Concept boards
define silhouette, timing, and material language; runtime effects are assembled
from five authored atlas parts instead of playing a baked full-effect image.

## Finishers

| Skill | Readable silhouette | Three-beat timing |
| --- | --- | --- |
| 千刃殺 | Horizontal metallic blade storm | Needle funnel → broad torrent → crossed blade impact |
| 焚天滅 | Compressed solar core and fire execution crescent | Collapse → rupture slash → incinerating debris |
| 雷獄穿心 | Rectangular thunder prison and straight lightning spear | Prison lock → instant pierce → puncture starburst |
| 天輪斷 | Three interlocking celestial rings split diagonally | Ring formation → divine sever → shearing ring shards |
| 霜葬 | Ground seal, closing ice coffin, heavy shatter | Frost seal → coffin close → burial shock and crystals |

## Named triggers

| Skill | Readable silhouette | Three-beat timing |
| --- | --- | --- |
| Iron Momentum | Forged-steel forward chevrons | Five ticks → momentum drive → armor lock |
| Ember Reprise | Repeated red-white sword traces and phoenix crest | Echo phrase → crossing reprise → wing crest |
| Battle Tempo | Five timing ticks and action-point diamond | Beat rail → synchronized pulse → AP resolve |
| Grand Strategy | Tactical diamond grid and navy-gold ward | Four paths → folded crest → protective shell |

The only fire-dominant identities are 焚天滅 and Ember Reprise. Other profiles
must retain metallic, lightning, celestial-geometric, frost-crystal, rhythm, or
tactical silhouettes even if later Combo mutations add a secondary element.
